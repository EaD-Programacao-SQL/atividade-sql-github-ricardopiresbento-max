# Reflexão sobre o uso dos media na aprendizagem de SQL

Responde de forma breve e honesta às questões:

1. **Que media foi mais útil para aprender SQL nesta atividade?**  
   (ex.: vídeos tutoriais, W3Schools, simulador SQL, GitHub, IA, outros...)
-- O media digital que mais me ajudou foi o GitHub. 

2. **Porquê?**  
   Explica o que esse media te permitiu fazer ou compreender melhor.
-- Porque pude acompanhar a evolução do meu código ao longo da atividade, ver as diferentes --versões, identificar onde tinha cometido erros e perceber claramente como fui melhorando. O GitHub ajudou-me a organizar melhor o trabalho e a refletir sobre cada alteração.
   
4. **Que dificuldades sentiste ao longo da atividade?**  
   (técnicas, de compreensão, de organização, uso das ferramentas, etc.)
-- A maior dificuldade foi perceber alguns erros de sintaxe nas consultas SQL. Às vezes um detalhe muito pequeno impedia o código de funcionar, e isso provocou alguma frustração inicial. Também tive dúvidas em escolher a melhor forma de estruturar certas consultas.

5. **Que estratégias usaste para ultrapassar essas dificuldades?**  
   (pedir apoio, rever vídeo, testar código, usar IA de forma crítica, etc.)
-- Os vídeos tutoriais foram úteis para rever os conceitos técnicos ao meu ritmo e perceber melhor a lógica por detrás de cada tipo de consulta. Também utilizei a IA de forma crítica, apenas para compreender porque é que uma consulta estava errada, sem pedir diretamente a solução. Além disso, testar diferentes versões no simulador ajudou-me a confirmar se estava a avançar na direção certa.

6. **O que mudarias na próxima vez que fizeres uma atividade deste tipo?**
   Organizaria melhor as minhas anotações e criaria uma lista de erros comuns, para evitar repetir as mesmas falhas. Também tentaria explorar mais recursos complementares, como o W3Schools, para ganhar mais confiança antes de avançar para consultas mais complexas.
